# Security Policy

## Supported versions

Security fixes are prioritized for the latest released version of IE Legacy Helper. Older releases may not receive fixes; users should upgrade when possible.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature, if enabled for this repository, to submit a report. Include a concise description, steps to reproduce using a sanitized test case, potential impact, and any suggested mitigation.

Do not include credentials, private URLs, page content, customer information, or confidential organizational data in a report.

## Scope

Security concerns may include unintended website access, excessive permissions, unsafe script injection, data collection or transmission, insecure storage, or vulnerabilities in compatibility shims.

This project is intended to operate locally and does not intentionally collect or transmit browsing data. Please report behavior that contradicts this design.
